Service

対応している4つの領域

制作、SEO・記事制作、AI検索対策（AIO・LLMO）、地図検索・MEO。制作と集客を切り離さず、同じ担当者が続けて見ることで判断のずれをなくします。

HOMEPAGE

ホームページ制作

公開後にご自身で更新できる状態までを含めて設計します。構成・原稿・実装・公開後の初期運用までを一人で担当するため、引き継ぎで内容が抜け落ちません。

SEO / CONTENT

SEO・記事制作

内部構造の点検から記事設計までを扱います。順位が動かない原因を、技術・内容・競合のどこにあるか切り分けたうえで、着手する順番を決めます。

AIO / LLMO

AI検索対策（AIO・LLMO）

ChatGPTやGeminiなどの生成AIが、情報源として引用しやすい構造にサイトを整えます。AIO（AI最適化）とLLMO（大規模言語モデル最適化）と呼ばれる領域です。構造化データと記述の粒度を見直し、現在どの程度参照されているかを定期的に確認します。

LOCAL

地図検索・MEO

Googleビジネスプロフィールとサイトの情報を一致させ、地域名を含む検索に対応します。写真と投稿の運用方法もあわせてお渡しします。

Works

制作実績

守秘のため、社名・地域名・サイトURLは掲載していません。業種と担当範囲のみ記載しています。

  • 01　CORPORATE / WEB

    スポーツ関連事業

  • 02　CARE / WORDPRESS

    介護老人保健施設

    WordPressのカスタムテーマで制作。ご家族が安心して問い合わせできる導線と、職員の方がご自身で更新できる構成にしています。

  • 03　TRADING / WORDPRESS

    水産物輸入卸

    取扱商品と企業信用が伝わる構成で設計。法人取引の問い合わせにつながる導線で構築しました。

  • 04　CONSTRUCTION / WEB

    電気設備・空調工事

    施工領域と対応力が一目で伝わる構成に整理。施工内容と対応エリアをまとめ、採用にも使える形にしています。

  • 05　CONSTRUCTION / WEB

    建具工事・内装施工

    理念・事業内容・採用・施工事例・ブログまでを設計し、職人の技術が伝わる写真主体のレイアウトで構築しました。

  • 06　NPO / WORDPRESS

    地域子育て支援センター

    一時預かり・親子遊び広場・育児相談といった、利用者が探す情報へ最短で届く設計。活動報告を継続発信できる形にしています。

Flow

ご依頼から公開まで

  1. STEP 01

    ご相談・現状の確認

    今のサイトと検索状況を確認し、課題が制作にあるのか運用にあるのかを切り分けます。

  2. STEP 02

    構成とお見積り

    必要なページと優先順位を整理し、費用と期間をお出しします。ここまでは費用をいただきません。

  3. STEP 03

    設計・原稿

    ワイヤーフレームと原稿を先に固めます。デザインから始めると、あとで文章が入らず作り直しになります。

  4. STEP 04

    デザイン・実装

    スマートフォンでの見え方を先に確認しながら進めます。表示速度は実装中に計測します。

  5. STEP 05

    公開・引き渡し

    更新手順をまとめてお渡しします。公開後の計測設定と初回の順位確認まで含みます。
